# Templates

This directory contains useful templates for kickstarting the development of a new ROS2 package.
- `cpp_package`: a sample C++ package, including `CMakeLists.txt`, `package.xml`, and source, header, and test files.
- `python_package`: a sample Python package, including `package.xml`, `setup.cfg`, `setup.py`, and source and test files. 
- `library_package`: a package to be used in other projects, stored in the `/core` rather than `/onboard` directory. This template is for C++.
- `readme`: a sample README that should be adapted and included with every package that you develop.
